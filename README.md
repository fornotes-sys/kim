# КиМ — сайт прихода

Самописный портал прихода в минималистичном византийском стиле.

## Планируемый функционал
- Главная страница, история и контакты прихода
- Расписание богослужений и календарь событий
- Новости и объявления
- Интернет-магазин мерча
- Пожертвования и подача записок
- Обращения и вопросы батюшке
- Административная панель с разграничением прав

## Стек (предварительный)
- Next.js + TypeScript
- PostgreSQL
- GitHub для контроля версий

## Статическая главная (прототип)

В папке [`docs/`](docs/) лежит свёрстанная главная страница на чистом HTML/CSS/JS, без сборки. Она сделана по визуальному референсу и готова к публикации через GitHub Pages (ветка `main`, папка `/docs`). Что заполнить перед запуском, описано в [`docs/README.md`](docs/README.md).

Её вёрстку и стили можно перенести в будущее приложение на Next.js.
