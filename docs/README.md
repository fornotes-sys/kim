# Сайт прихода храма свв. Кирилла и Мефодия на Пулковских высотах

Статическая главная страница: HTML + CSS + немного JavaScript, без сборки и зависимостей.
Открывается двойным щелчком по `index.html` или публикуется через GitHub Pages.

## Структура

```
index.html            главная страница
assets/css/styles.css стили (цвета и шрифты — в блоке :root вверху)
assets/js/main.js     меню, слайдер, календарь, прогресс сбора, записки
assets/img/           визуализации храма, эмблема, рисунок святых, мерч
assets/fonts/         Playfair Display (woff, кириллица + латиница)
```

## Публикация на GitHub Pages

1. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
2. Через минуту сайт будет доступен по адресу `https://fornotes-sys.github.io/kim/`.

Для приватного репозитория GitHub Pages доступен только на платном тарифе. На бесплатном тарифе репозиторий должен быть публичным.

## Что нужно заполнить перед запуском

| Где | Что |
|---|---|
| `assets/js/main.js`, `FUNDRAISING` | Собрано и цель сбора в рублях (пока `null` — карточка показывает «уточняется») |
| `index.html`, блок `calendar-data` | Записи по дням: память святых и пост. Сейчас проверен только 12 октября 2026; в остальные дни показывается дата, старый стиль и ссылка на полный календарь |
| `index.html`, `<!-- TODO -->` | Фото вида с Пулковских высот, креста и стройплощадки, фото событий |
| `index.html`, подвал | Ссылки на ВКонтакте, Telegram, YouTube; точный адрес |
| Ссылки с `data-soon` | Ведут на будущие разделы; пока при нажатии показывают «раздел готовится» |
| Формы записок | Приём не подключён: форма проверяет имена и честно сообщает, что записка не отправлена |
| Кнопки «Поддержать» | Платёжный сервис не подключён |

## Шрифты и лицензии

- **Playfair Display** (заголовки) — SIL Open Font License, файлы лежат в `assets/fonts/`.
- **Onest** (текст и интерфейс) — SIL Open Font License, подключается с Google Fonts в `index.html`.
- Коммерческий TT Norms в репозиторий не входит. Если у прихода есть лицензия на веб-использование, его можно вернуть через `@font-face` в `styles.css`.

## Изображения

- `hero-temple-*.jpg`, `temple-aerial.jpg` — проектные визуализации храма из материалов прихода.
- Файлы `*-ref.jpg` вырезаны из макета `01-reference.png` и увеличены. Это сгенерированные иллюстрации, а не фото прихода. Перед запуском их нужно заменить:
  - `event-*-ref.jpg` — на настоящие фото молебнов и событий;
  - `merch-ref.jpg` — на фото реального мерча (худи и кружки в линейке пока нет);
  - `pulkovo-ref.jpg` — на настоящее фото Пулковских высот.
- Новое фото кладётся под тем же именем, вёрстку менять не нужно.
- Цифры сбора в `main.js` — пример из макета, на сайте помечены как пример.
