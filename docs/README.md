# Сайт прихода храма свв. Кирилла и Мефодия на Пулковских высотах

Статическая главная страница: HTML + CSS + немного JavaScript, без сборки и зависимостей.
Открывается двойным щелчком по `index.html` или публикуется через GitHub Pages.

## Структура

```
index.html            главная страница
assets/css/styles.css стили (цвета и шрифты — в блоке :root вверху)
assets/js/main.js     меню, слайдер, календарь, прогресс сбора, записки
assets/js/hero-life.js  «живая» картинка храма на первом экране (времена года, ветер, погода)
assets/js/chapel-toy.js   живая иллюстрация в блоке «Строим вместе» (только компьютер)
assets/js/chapel-game.js  полная игра «Сложи сруб», открывается из неё кнопкой
assets/css/chapel-game.css стили обеих
assets/img/           визуализации храма, эмблема, рисунок святых, мерч
assets/fonts/         Old Standard TT, Fedorovsk, Playfair Display SC (woff)
```

## Публикация на GitHub Pages

1. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.
2. Через минуту сайт будет доступен по адресу `https://fornotes-sys.github.io/kim/`.

Для приватного репозитория GitHub Pages доступен только на платном тарифе. На бесплатном тарифе репозиторий должен быть публичным.

## Что нужно заполнить перед запуском

| Где | Что |
|---|---|
| `assets/js/main.js`, `FUNDRAISING` | Собрано и цель сбора в рублях (пока `null` — карточка показывает «уточняется») |
| `index.html`, блок `calendar-data` | Записи по дням: память святых и пост. Сейчас проверен только 12 октября 2026; в остальные дни показывается дата, старый стиль и ссылка на полный календарь |
| `index.html`, `<!-- TODO -->` | Фото вида с Пулковских высот, креста и стройплощадки, фото событий |
| `index.html`, подвал | Ссылки на ВКонтакте, Telegram, YouTube; точный адрес |
| Ссылки с `data-soon` | Ведут на будущие разделы; пока при нажатии показывают «раздел готовится» |

## Шрифты и лицензии

- **Old Standard TT** (заголовки) — SIL Open Font License (`assets/fonts/OldStandard-OFL.txt`), файлы лежат в `assets/fonts/`.
- **Onest** (текст и интерфейс) — SIL Open Font License, подключается с Google Fonts в `index.html`.
- Коммерческий TT Norms в репозиторий не входит. Если у прихода есть лицензия на веб-использование, его можно вернуть через `@font-face` в `styles.css`.

## Времена года на первом экране

Картинка храма меняется по временам года, у каждого сезона своя «жизнь» (ветер, облака, дождь, снег, лепестки, птицы — `assets/js/hero-life.js`, настройки в объекте `SEASONS`).

| Сезон | Когда показывается (по Москве) | Файлы |
|---|---|---|
| ранняя осень `early-autumn` | 1 сентября – 15 октября | `assets/img/hero.webp` (утверждённое фото), маски `hero-life-masks.webp` |
| поздняя осень `late-autumn` | 16 октября – 30 ноября | `assets/img/seasons/late-autumn.webp`, `late-autumn-masks.webp` |
| зима `winter` | декабрь – февраль | `assets/img/seasons/winter.webp`, `winter-masks.webp` |
| весна `spring` | март – май | `assets/img/seasons/spring.webp`, `spring-masks.webp` |
| лето `summer` | июнь – август | `assets/img/seasons/summer.webp`, `summer-masks.webp` |

- Сезон выбирает маленький скрипт в `<head>` `index.html` до отрисовки, поэтому грузится только фото текущего сезона. Там же объект `AUTO`: если какой-то сезон нужно временно не показывать, его можно подменить, например `var AUTO = { winter: 'late-autumn' };`.
- Посмотреть любой сезон: `?season=winter` (или `early-autumn`, `late-autumn`, `spring`, `summer`), например `https://fornotes-sys.github.io/kim/?season=winter`. Добавьте `&life=demo` — события (дождь, птица, блик, просвет солнца) будут происходить часто.
- В правом верхнем углу фото — маленький переключатель сезонов: посетитель может посмотреть храм в любое время года.
- Маски (`*-masks.webp`, половинное разрешение): R — небо (там плывут облака), G — листва (оттуда срываются листья и лепестки), B — золото купола и крестов (по нему бежит блик). Карта ветра `hero-wind.webp` общая для всех сезонов.
- При «уменьшить движение» в системе анимации нет, фото и переключатель работают.

Сезонные фото сделаны из `hero.jpg` обработкой по маскам (храм и кресты не меняются), скрипт — `tools/seasons/make_seasons.py` (Python: numpy, opencv, Pillow, scipy). Запуск из корня репозитория: `python3 tools/seasons/make_seasons.py` (или с названиями сезонов).

### Свои сезонные картинки

Если сделать сезонную версию фото во внешнем редакторе (ChatGPT, Gemini, Photoshop «Генеративная заливка» и т. п.), положите её в `docs/assets/img/seasons/src/` под именем сезона: `winter.jpg`, `spring.png`, `summer.webp`, `late-autumn.jpg`. Кадр — как у `hero.jpg` (1444×1089, храм на том же месте, кресты целые). Затем попросите Claude: «возьми мои сезонные картинки» — он совместит кадр с исходным, проверит храм и кресты, сожмёт и построит для неё маски.
